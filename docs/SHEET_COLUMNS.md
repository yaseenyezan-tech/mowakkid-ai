# تبويبات Google Sheets وأعمدتها

أنشئ ملف Google Sheets واحداً، وبداخله **أربعة تبويبات بهذه الأسماء الإنجليزية حرفياً**: `Orders` و`Sessions` و`Messages` و`Errors`. لا تغيّر ترتيب الأعمدة. السطر الأول عناوين، والبيانات من السطر الثاني. لا تضف عنواناً أو جدولاً آخر فوق الجدول أو بجانبه، ولا تدمج خلايا. اترك الملف فارغاً من الأمثلة عند البدء.

اختَر تنسيق **نص عادي / Plain text** للأعمدة قبل الاستخدام، خصوصاً أرقام الهواتف والمعرّفات. البرنامج يكتب النصوص حرفياً ولا يحوّل نص الزبون إلى صيغة Sheets. السعر والإحداثيات تُكتب كأرقام. التواريخ بصيغة ISO 8601 بتوقيت UTC؛ مثالها `YYYY-MM-DDTHH:mm:ss.sssZ`.

## Orders

انسخ السطر التالي إلى A1؛ الفاصل بين العناوين هو Tab. إذا ظهر كله داخل خلية واحدة، افتح Sheets بوضع «موقع سطح المكتب» واختر «البيانات ← تقسيم النص إلى أعمدة ← Tab»، أو اكتب العناوين كل واحد في خلية حسب الجدول.

```tsv
order_id	created_at	customer_name	product	price_iqd	customer_phone	status	latitude	longitude	maps_url	cancel_reason	edit_request	updated_at
```

| العمود | الاسم الحرفي | المعنى |
|---|---|---|
| A | order_id | معرّف عشوائي بالشكل `MW-` ثم 16 رمزاً من 0–9 وA–F؛ لا تعِد استخدامه |
| B | created_at | وقت إنشاء الطلب |
| C | customer_name | اسم الزبون |
| D | product | وصف المنتج من البائع، حتى 200 حرف |
| E | price_iqd | سعر المنتج بالدينار العراقي؛ عدد صحيح موجب، لا يشمل أجوراً غير محددة |
| F | customer_phone | رقم دولي بدون `+` أو مسافات؛ العراقي يبدأ بـ`964` |
| G | status | `pending` أو `confirmed` أو `cancelled` |
| H | latitude | خط العرض، يبقى فارغاً قبل حفظ الموقع |
| I | longitude | خط الطول |
| J | maps_url | رابط Google Maps للإحداثيات |
| K | cancel_reason | سبب الإلغاء كما كتبه الزبون |
| L | edit_request | ملاحظات التعديل مع وقتها، آخر 4000 حرف؛ مراجعتها مسؤولية البائع |
| M | updated_at | آخر تحديث |

لا يتحول الطلب إلى `confirmed` بالضغط وحده: يجب إرسال موقع صحيح بعد طلبه. الإلغاء لا يكتمل إلا بعد كتابة السبب. الطلب النهائي لا يُفتح مجدداً بزر قديم؛ يتواصل الزبون مع البائع لأي تغيير جديد.

## Sessions

```tsv
phone	order_id	state	last_customer_at	window_expires_at	updated_at
```

| العمود | الاسم الحرفي | المعنى |
|---|---|---|
| A | phone | المفتاح: رقم الزبون الدولي؛ صف واحد لكل رقم |
| B | order_id | الطلب الحالي، أو فارغ |
| C | state | `idle`, `choosing`, `awaiting_location`, `awaiting_cancel_reason`, `editing`, `closed` |
| D | last_customer_at | وقت آخر رسالة مقبولة من الزبون، مأخوذ من Meta |
| E | window_expires_at | وقت الرسالة + 24 ساعة |
| F | updated_at | وقت آخر تحديث للسجل |

تُحوّل الأرقام `٠١٢٣٤٥٦٧٨٩` و`۰۱۲۳۴۵۶۷۸۹` إلى الإنجليزية، والرقم العراقي المحلي `07…` إلى `9647…`. إذا مضت 24 ساعة بين رسالتين تُصفّر حالة الانتظار القديمة. رسالة جديدة من الزبون تفتح نافذة جديدة، وعليه إرسال رقم الطلب مجدداً إذا انتهت الجلسة.

## Messages

```tsv
message_id	phone	order_id	received_at	processed_at	delivery_status	reply_json	window_expires_at	whatsapp_message_id	sent_at	last_error
```

| العمود | الاسم الحرفي | المعنى |
|---|---|---|
| A | message_id | معرّف Meta للرسالة الواردة؛ صف واحد لكل معرّف |
| B | phone | رقم المرسل بعد التطبيع |
| C | order_id | الطلب المرتبط، إن عُرف |
| D | received_at | وقت رسالة الزبون من Meta |
| E | processed_at | وقت تجهيز المعالجة |
| F | delivery_status | `prepared`, `sent`, `failed`, `expired`, `stale` |
| G | reply_json | الرد المحفوظ قبل الإرسال؛ فارغ للرسائل التي لا تُرسل لها إجابة |
| H | window_expires_at | حد الإرسال لهذا الرد |
| I | whatsapp_message_id | معرّف Meta لقبول الرد، وليس دليلاً على قراءته أو تسليمه |
| J | sent_at | وقت قبول الإرسال |
| K | last_error | رمز خطأ مختصر فقط؛ مثلاً `WINDOW_EXPIRED` أو رمز Meta |

`prepared`: تغييرات الطلب والرد محفوظة معاً ولم يُسجّل قبول الإرسال بعد. `failed`: فشل الإرسال، والرد محفوظ لإعادة المحاولة عند إعادة معالجة **نفس message_id**. `sent`: قبول Meta للإرسال؛ التكرار يُتجاهل. `expired`: انتهت نافذة الرد. `stale`: رسالة أقدم من آخر رسالة تمت معالجتها؛ لا تُرجع حالة الطلب للوراء.

لا ترتّب أو تحذف صفوف هذا التبويب أثناء العمل؛ تحديث نتيجة الإرسال يستخدم رقم الصف المقروء في نفس التنفيذ. لا تمسح سجل الرسائل الذي قد تعيد Meta تسليمه. حذف السجل يلغي حماية التكرار لذلك المعرّف.

## Errors

```tsv
timestamp	workflow	execution_id	node	error_code	message_id	message
```

| العمود | الاسم الحرفي | المعنى |
|---|---|---|
| A | timestamp | وقت الخطأ |
| B | workflow | اسم سير العمل |
| C | execution_id | رقم التنفيذ، وقد يكون فارغاً في خطأ Gemini أو فشل التفعيل |
| D | node | العقدة المرتبطة |
| E | error_code | نوع/رمز مختصر للخطأ |
| F | message_id | معرّف الرسالة إن توفر، دون نصها أو رقم الزبون |
| G | message | وصف آمن؛ التفاصيل الحساسة تبقى في شاشة Executions المحمية |

كل اتصال بـSheets يستخدم نفس Google OAuth2 credential. معرّف ملف Sheets في متغير `GOOGLE_SHEET_ID`؛ معرّفات التبويبات الداخلية تُكتشف تلقائياً بالاسم. لا تضفها إلى JSON.

حصر التعديل: حساب Google المرتبط ومالك المتجر فقط. تجنّب أي سكربت آخر يكتب في هذه التبويبات. راجع ملاحظات الزبائن بتوقيف السير قبل تغيير الصفوف أو ترتيبها، ثم فعّله مجدداً. هذه شروط اتساق مهمة لأن Sheets لا يفرض مفاتيح فريدة أو أقفالاً بين عدة أنظمة.
